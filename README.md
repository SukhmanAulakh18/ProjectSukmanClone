# Library Management System

A comprehensive library management system built with Java.

## Features
- Book catalog management
- Member registration and management
- Book borrowing and returning
- Search functionality

## Getting Started
This project demonstrates professional Git workflow with proper branching strategy.

### Prerequisites
- Java 8 or higher
- Git

### Installation
1. Clone the repository
2. Navigate to the project directory
3. Compile and run the Java files

## Contributing
Please follow the branching strategy:
- `main`: Production-ready code
- `staging`: Pre-production testing
- Feature branches: Development of new features
